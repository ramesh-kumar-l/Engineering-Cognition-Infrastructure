# Research

This directory holds research artifacts that inform decisions but are not themselves decisions. Each file is a self-contained investigation: a question, a method, evidence, and a conclusion that feeds an ADR or roadmap update.

## Filename convention
`YYYY-MM-DD-short-kebab-title.md`

## File template
```markdown
# <title>

- **Date:** YYYY-MM-DD
- **Author:** <name>
- **Phase:** P<N>
- **Question:** What are we trying to learn?

## Method
How we investigated. Sources, experiments, comparisons.

## Findings
Evidence. Numbers. Citations.

## Conclusion
What we now believe and what action it implies.

## Follow-ups
- [ ] ADR-NNN to ratify the implied decision (if any).
- [ ] Risks to add to the risk register.
```
